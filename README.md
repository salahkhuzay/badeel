# بديل — Badeel 🏙️

> **بديل — خيارك الأفضل للبيع والشراء في منبج**

منصة إعلانات مبوبة محلية (C2C Marketplace) مخصّصة لمدينة **منبج** (محافظة حلب، سوريا)، متخصصة
بـ **العقارات** و**السيارات والمركبات**، مع عرض الأسعار بالعملتين (الدولار والليرة السورية)،
ونظام **مراجعة إدارية (موافقة مسبقة)** قبل النشر، وبنية جاهزة للتوسّع الإقليمي إلى حلب.

---

## 1) التقنيات المستخدمة

| الطبقة | التقنية |
|---|---|
| الواجهة | React 18 + Next.js 14 (App Router) |
| الأنماط | Tailwind CSS 3 (مع الوضع الليلي بالكامل) |
| الأيقونات | Lucide React |
| اللغة والاتجاه | عربي أصلي — RTL (`dir="rtl"`) |
| إدارة الحالة | React Context + `useReducer` (Mock Store) + حفظ في `localStorage` |
| PWA | `manifest.webmanifest` + Service Worker (`sw.js`) — جاهزة للتركيب على الجوال |
| الخطوط | **خطوط النظام العربية** (system-ui / Segoe UI / Tahoma / Noto Kufi / Cairo) — بلا أي خط يُحمَّل من الشبكة |

> **ملاحظة:** لا توجد أي مكتبة حالة خارجية (Redux/Zustand)؛ المخزن مكتوب يدوياً وحجم الحزمة الأولية
> ≈ 87 kB فقط، والصفحة الرئيسية ≈ 115 kB — أي أنها تعمل بسلاسة على الاتصالات الضعيفة.

## 2) تشغيل المشروع

```bash
npm install          # تثبيت الحزم (تم بالفعل داخل هذا الـ workspace)
npm run dev          # وضع التطوير على http://localhost:3000
npm run build        # بناء الإنتاج
npm run start        # تشغيل نسخة الإنتاج على 0.0.0.0:3000
```

### الدخول إلى لوحة التحكم (محمي)
```
اسم المستخدم: admin
كلمة المرور: (كلمة المرور الافتراضية تُسلَّم بشكل خاص — لا تُنشر في المستودع العام)
```

- كلمة المرور **لا تُخزَّن كنص صريح**: تُحوَّل إلى بصمة `PBKDF2-SHA256` (120,000 تكرار + ملح خاص)
  ولا يمكن استخراجها من ملف البيانات، ولا يوجد أي نص لكلمة المرور في الكود أو في الواجهة.
- لأسباب أمنية **لا تُعرض أي تلميحات أو بيانات دخول داخل شاشة الدخول**، ولا يوجد زر تعبئة تلقائية.
- قفل مؤقت تلقائي بعد **5 محاولات فاشلة** لمدة **10 دقائق**، وجلسة تنتهي بعد **20 دقيقة**
  (القيم قابلة للتعديل من: الإعدادات والأمان ← سياسة الجلسة والقفل).
- زر «خروج من جميع الأجهزة» لإبطال أي جلسة قديمة.
- من غيّر كلمة المرور ظهر له تنبيه دائم في اللوحة حتى التغيير (`passwordChanged`).

## 4) الميزات المُنفَّذة

### أ) محرّك العملة المزدوجة 💵
- مفتاح عام في الشريط العلوي (`$ دولار` / `ل.س ليرة`) يبدّل **كل أسعار المنصة فوراً**.
- كل إعلان يخزّن: `price` (بعملة الإدخال) + `currency` + `priceUsd` + `priceSyp`.
- البطاقة وصفحة الإعلان تعرضان دائماً **السعر + المعادل** (مثال: `$ 38,000` وتحت `≈ 494 مليون ل.س`).
- الفلترة بنطاق السعر تُدخل بعملة العرض وتُحوَّل داخلياً إلى الدولار كعملة مرجعية.
- سعر الصرف قابل للتعديل من لوحة التحكم مع معاينة فورية لأثر التعديل.

### ب) الموقع الجغرافي 📍 (المدينة فقط — بلا أحياء)
- **أُلغيت الأحياء والمناطق بالكامل بناءً على طلب صاحب المشروع** — لا قوائم ولا إدخال يدوي:
  حقل الموقع في نموذج النشر أصبح **المدينة** فقط (منبج افتراضياً).
- من يحتاج توضيحاً دقيقاً للموقع (حي، قرية، معلم قريب، طريق) يكتبه بحرية داخل وصف الإعلان.
- فلتر البحث يعرض قائمة **المدن المفعّلة** فقط — والمسؤول يفعّل مدينة جديدة (حلب مثلاً) من لوحة
  التحكم لتظهر في النماذج والفلاتر **بدون أي تعديل برمجي**.
- البيانات مخزّنة كـ `City[]` (DB-ready)؛ وحقول المنطقة القديمة تُنظَّف تلقائياً من بيانات المستخدمين
  المحفوظة عند أول فتح (ترحيل داخلي في `normalize`).

### ج) نماذج ذكية حسب التصنيف 🧠 — سبعة تصنيفات

**① العقارات:** شقة سكنية · منزل عربي · أرض بناء · أرض زراعية · محل تجاري · مستودع
→ نوع التعامل (**بيع / إيجار شهري / إيجار سنوي**) + المساحة (م² أو **دونم** للأراضي) +
وضع الأوراق (طابو أخضر / حكم محكمة / وكالة عقارية / عرقاري - سياق) + خيار «السعر قابل للتفاوض».

**② سيارات ومركبات:** سيارة سياحية · شاحنة/بيك أب · دراجة نارية · آليات ثقيلة/جرار زراعي
→ **ماركة بالأيقونات + موديل من سوق الماركة + سنة صنع (1975–2026) + نوع التعامل
(بيع / إيجار يومي / إيجار شهري)** + حالة الجسم + نوع الوقود + **نمرة التسجيل** + خيار «ماركة أخرى»
بكتابة الماركة والموديل يدوياً.

**③ هواتف مستعملة وجديدة:** ماركة الهاتف بالأيقونة الرسمية ← الموديل من قائمة الماركة ← **الحالة**
(جديد / مستعمل كالجديد / بحالة جيدة / يحتاج صيانة) ← **سعة التخزين** (64GB – 1TB+)، مع تصنيفات
فرعية (آيفون، سامسونغ، شاومي، هواوي، أوبو، ريلمي، فيفو، نوكيا، إنفينيكس، هونر، ون بلس، موتورولا،
تابلت، إكسسوارات وقطع)، وفرز سوق الهواتف **بنفس أيقونات الماركات**.

**④ أثاث منزلي** · **⑤ أدوات كهربائية** · **⑥ ملابس وأزياء** — لكل تصنيف قائمة أنواع خاصة:
- أثاث: غرف نوم، كنبات وجلسات، طاولات وسفرة، خزائن، أطقم مطبخ، مكتبات، سجاد، ستائر، مفروشات، أطقم حدائق.
- أجهزة: ثلاجات، غسالات، مكيفات، تلفزيونات، مولّدات، سخانات، أفران ومواقد، شفاطات، مكانس، أدوات مطبخ.
- ملابس: رجالي، نسائي، أطفال، أحذية، حقائب، إكسسوارات، عبايات، فساتين، رياضية.
→ في كل واحد: **النوع + الحالة** (جديد / مستعمل بحالة ممتازة / مستعمل بحالة جيدة / يحتاج صيانة)،
وللأجهزة ماركة الجهاز، وللملابس المقاس.

**⑦ وظائف (عرض وظيفة / طلب عمل):** مجالات العمل + نوع الدوام (كامل/جزئي/ورديات/حر/تدريب) +
سنوات الخبرة المطلوبة، و**الأجر اختياري** — إن تُرك فارغاً يُعرض «الأجر: يُتفق عليه» ولا يُطلب سعر.

النموذج يتغيّر ديناميكياً: اختيار «أرض زراعية» يفعّل وحدة الدونم، و«آليات ثقيلة» يجعل سنة الصنع
إلزامية، و«وظائف» يخفي حقل السعر ويُظهر خانة الأجر… إلخ، مع تحقق مُفصّل لكل حقل ومعاينة حيّة
وفيها **شاشة معاينة كاملة قبل الإرسال** كما كان.

#### ماركات السيارات والهواتف — شعارات رسمية
**ماركات السيارات (17 ماركة + «ماركة أخرى»)**، و**ماركات الهواتف (12 ماركة + «ماركة أخرى»)**.
**هيونداي · كيا · تويوتا · مارسيدس · ميتسوبيشي · جيب · لاندروفر · رنج روفر · بي إم دبليو · أودي ·
فولكس فاغن · مازدا · نيسان · سكودا · شام · بيجو · رينو** + «ماركة أخرى» بكتابة يدوية.

- كل ماركة لها **أيقونة الشعار الرسمي** (SVG مضمّن بلا أي طلب شبكة، بلون الماركة الرسمي:
  هيونداي `#002C5E`، تويوتا `#EB0A1E`، بي إم دبليو `#0066B1`…) — الـ Monogram لا يظهر إلا
  لخيار «ماركة أخرى» حين لا يوجد شعار.
- النقر على أي أيقونة يفتح **سوق موديلاتها**: مثال مارسيدس (86 موديلاً): S280 · S300 · S320 · S350 ·
  S400 · S430 · S500 · S550 · S600 · S63 · E200–E500 · C180–C63 · الفئات S/E/C/A/B/G/M/R/V ·
  CLA/CLS/GLA/GLB/GLC/GLE/GLS/GLK/SLK · ML250–ML500 · GL320–GL500 · G300/G500/G63 · فيتو ·
  فيانو · سبرينتر · أكتورس · وبنز قديم (W123/W124) — وكل ماركة بنفس المستوى من التفصيل
  (إجمالي 514 موديلاً عبر 29 ماركة سيارات وهواتف).
- **تصنيف مستقل حسب سنة الصنع**: شرائح `2020+` · `2015–2019` · `2010–2014` · `2005–2009` ·
  `2004 وما قبل`، أو نطاق يدوي «من سنة — إلى سنة»، مع فرز «الأحدث صنعاً / الأقدم صنعاً».
- بحث ماركة ذكي يقبل الكتابات الشائعة (مرسيدس/مارسيدس، لاند روفر/لاندروفر...).

#### نمر التسجيل المعتمدة (ستّ نمر)
`مجمرك` · `إدخال جديد` · `نمرة إدلب` · `نمرة الشمال` · `نمرة الديمقراطي` · `نمرة النظام`

السعر يُعرض بجانب العملة **مع اللاحقة الصحيحة**: «/ يومياً» أو «/ شهرياً» أو «/ سنوياً»، وحالة
الإعلان تدعم **مُباع** و**مؤجَّر** معاً.

### د) الإجراءات السريعة (One-Click) ⚡
- **واتساب** برسالة جاهزة حرفياً: `مرحباً، أنا مهتم بإعلانك على منصة بديل: [عنوان الإعلان]`
- **اتصال مباشر** (`tel:`) مع تطبيع رقم الهاتف السوري تلقائياً (`0955…` → `+963955…`).

### د-2) التواصل والدعم 📞
رقم الدعم **0933177597** يظهر في **الترويسة العلوية** و**قائمة الجوال** و**التذييل** و**صفحة كيف
يعمل بديل؟** بثلاث صيغ جاهزة:

| العنصر | المكان | السلوك |
|---|---|---|
| رقم الهاتف | الترويسة · التذييل · كيف يعمل | يُعرض محلياً `0933177597` ويُبنى كـ `tel:+963933177597` |
| زر/أيقونة **واتساب** | الترويسة · قائمة الجوال · التذييل · كيف يعمل | `wa.me` برسالة عامة جاهزة «مرحباً، أرغب بالاستفسار عن منصة بديل» |
| أيقونة **فيسبوك** | الترويسة · الترويسة السفلية · التذييل (عمود التواصل) | تفتح الصفحة الرسمية لبديل — يُضبط من الإعدادات، والافتراضي الآن **الرابط الرسمي** `https://www.facebook.com/share/1cmT94zzJk/` |

كل ذلك يُدار من: **الإعدادات والأمان ← بيانات التواصل والدعم** (الرقم ومفتاح الدولة ورابط فيسبوك).

### هـ) لوحة التحكم الإدارية 🛡️
| التبويب | المحتوى |
|---|---|
| **نظرة عامة** | بطاقات: إجمالي الإعلانات، بانتظار المراجعة، مرفوضة، المشاهدات + توزيع التصنيفات (أشرطة) + **أكثر الماركات في السوق** + إعلانات آخر 7 أيام |
| **قيد المراجعة** | طابور المراجعة: بطاقة تفصيلية لكل إعلان معلّق + «موافقة ونشر» / «رفض مع سبب» / «تمييز» / «تحقّق من المُعلن» عبر واتساب |
| **إدارة الإعلانات** | جدول كامل: موافقة، رفض، **تم البيع**، **تم التأجير**، تمييز، إعادة نشر، حذف، بحث وفلترة بالحالة |
| **المدن** | تفعيل/إلغاء تفعيل أي مدينة (حلب مثلاً) لتظهر فوراً في نموذج النشر وفلتر البحث، مع عدّاد الإعلانات لكل مدينة |
| **الإعدادات والأمان** | سعر الصرف، رقم الدعم ومفتاح واتساب **ورابط فيسبوك**، الشعار، **تغيير كلمة المرور**، **سياسة الجلسة والقفل**، إبطال الجلسات، إعادة تعيين بيانات المنصة |
| **سجل العمليات** | تتبّع زمني لكل إجراء إداري مع الرقم المرجعي للإعلان — **بما في ذلك محاولات الدخول الفاشلة وتغيير كلمة المرور** |

**دورة حياة الإعلان:** `pending` (لا يُرى للجمهور) → `active` → `sold` / `rented`، أو `rejected`
مع سبب إلزامي يظهر للمُعلن.

## 6) الانتقال إلى الإنتاج (Roadmap تقني)

البنية الحالية **Mock-first** ومقصودٌ أن تكون الاستبدالات محدودة النطاق:

1. **قاعدة بيانات:** استبدال `lib/store.tsx` بنداءات API (مثال: Next Route Handlers +
   PostgreSQL/Supabase). جدول `ads` يطابق `lib/types.ts` حرفياً، والمدن في جدول `cities`
   مع `city_id`.
2. **المصادقة:** استبدال `login()` بمصادقة حقيقية (JWT/Session + أدوار: `admin` / `moderator`)،
   وحماية مسارات `/admin` على مستوى الخادم.
3. **رفع الصور:** تحويل معرض «الصور النموذجية» إلى رفع حقيقي (R2/S3) مع ضغط صور من طرف العميل
   لتقليل الاستهلاك على الاتصالات الضعيفة.
4. **سعر الصرف:** جدول `exchange_rates` + تحديث يومي (cron) بدل القيمة اليدوية.
5. **التوسّع:** `INSERT INTO cities (name,'حلب')` + أحياؤها → تظهر تلقائياً في النماذج والفلاتر.
6. **إشعارات:** واتساب Business API لإبلاغ المُعلن بحالة إعلانه (مقبول/مرفوض).

## 7) قرارات تصميمية مهمة

- **الموافقة المسبقة إلزامية** — لا يُنشر أي إعلان تلقائياً، وهذا مطبَّق في المخزن نفسه
  (`status: "pending"` عند الإرسال) وليس مجرد واجهة.
- **العملتان معاً دائماً** — لا يمكن لمستخدم أن يرى سعراً بعملة واحدة فقط؛ المعادل يظهر تحت السعر.
- **الأداء أولاً** — لا مكتبات UI ثقيلة ولا خطوط إلزامية، وتصدير ثابت (SSG) لصفحات التصنيف والبحث،
  وخدمة صور متدرّجة عبر Service Worker لمن يعاني اتصالاً متقطعاً.
- **العربية ليست ترجمة** — التصنيفات والرسائل مكتوبة بلغة أهل السوق في منبج
  («طابو أخضر»، «خالية العلام أورجينال»، «نمرة منبج»، «عرقاري - سياق»).

4. **مهم:** قبل الضغط على Deploy، غيّر **Project Name** إلى اسم فريد تحجزه لك، مثل
   **`badeel-online`** (الاسم المعتمد) — لأن الاسم `badeel` محجوز لجهة أخرى

   لا حاجة لحجز نطاق: المشروع يكتشف رابطه تلقائياً من Vercel.

بدائل مكافئة: **Netlify** (netlify.com/new) · **Cloudflare Pages** · أي خادم Node.js
(`npm ci && npm run build && npm start`).

### ② ضبط رابط الموقع داخل المشروع (مهم لخريطة الموقع)

في لوحة Vercel: `Project → Settings → Environment Variables` وأضف:

| الاسم | القيمة |
|---|---|
| `NEXT_PUBLIC_SITE_URL` | **اختياري**: دومينك الخاص فقط (مثل `https://badeelonline.com`). على Vercel **لا تحتاجه** — الرابط يُكتشف تلقائياً من اسم مشروعك (`badeel-online`). |
| `NEXT_PUBLIC_GOOGLE_SITE_VERIFICATION` | رمز التحقق من Search Console (الخطوة ③) |

**كيف يُحدَّد الرابط؟** بترتيب الأولوية (راجع `lib/site.ts`): `NEXT_PUBLIC_SITE_URL` ←
`VERCEL_PROJECT_PRODUCTION_URL` (تلقائي) ← `VERCEL_URL` ← `localhost` للتشغيل المحلي.
لا يوجد أي عنوان ثابت في الكود، فلا يمكن أن تشير خرائط الموقع لموقع جهة أخرى.

### ③ الظهور في نتائج Google (Search Console)

1. افتح <https://search.google.com/search-console> → **Add property**.
2. اختر **URL prefix** واكتب رابط موقعك الكامل (رابط Vercel الخاص بمشروعك، أو نطاقك).
3. طريقة التحقق الأسهل: **HTML tag** → انسخ قيمة `content` فقط (سلسلة الرمز) وضعها في
   المتغيّر `NEXT_PUBLIC_GOOGLE_SITE_VERIFICATION` في Vercel ثم Redeploy، وارجع واضغط **Verify**.
   (أو استخدم التحقق عبر DNS بـ TXT إن كان لديك دومين خاص.)
4. من القائمة الجانبية: **Sitemaps** → أضف `sitemap.xml` → Submit.
5. من **URL Inspection**: الصق رابط الصفحة الرئيسية → **Request Indexing**.
6. تابع تبويب **Pages** لمعرفة عدد الصفحات المفهرَسة بعد أيام.

### ④ جدول زمني واقعي

| المدة | ما يحدث |
|---|---|
| 0–24 ساعة | Verifivation + بدء الزحف، وقد تظهر علامة Google على الموقع |
| 2–7 أيام | فهرسة الصفحة الرئيسية وصفحتي التصنيفات |
| 2–6 أسابيع | ظهور أول النتائج في البحث بالاسم «بديل منبج» أو «عقارات منبج» |

نصائح لتسريع الظهور محلياً:
- أنشئ **Google Business Profile** لمشروعك (منبج، حلب) — يظهر في نتائج الخرائط والبحث المحلي.
- شارك رابط الموقع على صفحات فيسبوك المحلية ومجموعات منبج؛ الروابط الخارجية تُسرّع الفهرسة.
- استخدم كلمات البحث كما يكتبها الناس فعلاً: «شقة للبيع في منبج»، «منزل عربي منبج»،
  «سيارة للبيع منبج» — وهي موجودة أصلاً في عناوين وأوصاف الصفحات.
- حدّث الإعلانات بانتظام: محتوى جديد = زيارات زحف أكثر.

GitHub Pages يستضيف **ملفات ثابتة فقط**، ولا يشغّل Next.js بخادم. يمكن تحويل المشروع إلى

### 10.5 التخلص من النسخة القديمة في المتصفح (تحديث فوري) + إصلاح ميل الصفحة

**المشكلة:** بعد كل تحديث كان بعض المستخدمين يرون نسخة قديمة (مثلاً رقم الدعم السابق) لأن
المتصفح/العامل المخدِّم (Service Worker) يحتفظ بصفحة قديمة، وكانت صفحة الرئيسية تظهر مزاحة على
الجوال (نصف الصفحة خارج الشاشة) بسبب تجاوز أفقي في قسم من الشبكة.

**ما نُفِّذ:**

| البند | التفصيل |
|---|---|
| **ترويسات منع التخزين** | `next.config.mjs`: صفحات HTML بـ `Cache-Control: no-store، no-cache` و`Pragma: no-cache`؛ و`/sw.js` بـ `no-cache` + `Service-Worker-Allowed: /`. الأصول المجزَّأة `_next/static/*` تبقى قابلة للتخزين الطويل. |
| **Service Worker v3** | لا يخزّن أي صفحة HTML ولا ملفات JS/CSS إطلاقاً — يجلبها من الشبكة دائماً؛ التخزين للصور فقط + صفحة «لا يوجد اتصال». حذف كل الكاشات القديمة تلقائياً عند التنشيط. |
| **تحديث تلقائي** | `lib/pwa.ts`: فحص تحديثات فوري (`updateViaCache: none`)، `skipWaiting`، وإعادة تحميل واحدة عند وصول نسخة جديدة. |

## 10.10 — كشف رابط الموقع تلقائياً بدل العنوان الثابت (2026-10-12)

**المشكلة:** كان `app/sitemap.ts` و`app/robots.ts` و`app/layout.tsx` تستخدم عنواناً افتراضياً ثابتاً
`https://badeel.vercel.app` — وهو **مملوك لجهة أخرى** («بدائل المستقبل للطاقة المتجددة»)، أي أن
خرائط الموقع ووسوم canonical كانت قد تشير إلى موقع طرف ثالث إن لم يُضبط المتغيّر.

**الحل — ملف جديد `lib/site.ts`** يحلّ الرابط بترتيب أولوية، بلا أي عنوان ثابت في الكود:

| # | المصدر | متى يُستخدم |
|---|---|---|
| ① | `NEXT_PUBLIC_SITE_URL` | إن كان لديك نطاق خاص |
| ② | `VERCEL_PROJECT_PRODUCTION_URL` | تلقائياً على Vercel (دومين مشروعك) |
| ③ | `VERCEL_URL` | تلقائياً لروابط المعاينة على Vercel |
| ④ | `http://localhost:3000` | للتشغيل المحلي فقط |

ويُستخدم `SITE_URL` الآن في: `app/sitemap.ts` · `app/robots.ts` · `metadataBase` في `app/layout.tsx`.
كما يُطلق الملف **تنبيهاً في سجل البناء** إن بُني للإنتاج بلا رابط مضبوط.

**التحقق العملي:** ببناءٍ مع `VERCEL_PROJECT_PRODUCTION_URL=badeel-sy.vercel.app` صار المولَّد:
`sitemap.xml` → كل الروابط `https://badeel-sy.vercel.app/...` و`robots.txt` → `Host: https://badeel-sy.vercel.app`
(لا أثر للعنوان القديم). واختُبرت الحالات الخمس: نطاق خاص ببروتوكول وبلا بروتوكول، ومحاكاة Vercel، والرابط المحلي.

**النتيجة:** لا تحتاج حجز نطاق إجبارياً — يكفي اختيار **اسم مشروع فريد** على Vercel، ويُكتشف الرابط
تلقائياً. وإن حجزت نطاقاً لاحقاً فاضبط `NEXT_PUBLIC_SITE_URL` فقط.

### 10.22 سعر الصرف العام عبر Upstash KV — تعديله من اللوحة يسري على كل الزوار (2026-10-13)

**المشكلة التي حُلّت:** المنصة بلا خادم لإدارة المحتوى، فكان سعر الصرف يُحفظ في
`localStorage` — أي في متصفح المسؤول وحده، بينما يرى بقية الزوار سعر الكود الثابت.

**الحل:** مخزن **Upstash KV** (`upstash-kv-beige-ridge`) مرتبط بمشروع Vercel `badeel-online`
(يحّقن Vercel تلقائياً `KV_REST_API_URL` و`KV_REST_API_TOKEN` و`KV_REST_API_READ_ONLY_TOKEN`)،
وفوقه مسار خادم صغير:

| المسار | الوظيفة | الحماية |
|---|---|---|
| `GET /api/rate` | يقرأ `site:rate` + `site:rateUpdatedAt` بتوكن **القراءة فقط** | عام؛ وعند غياب المخزن أو انقطاعه يرجع سعر الكود احتياطياً (`source: "default"`) فلا يرى الزائر خطأً أبداً |
| `POST /api/rate` | ينشر سعر جديد (`{rate, key}`) بتوكن الكتابة | ‏`RATE_WRITE_KEY` من متغيّرات Vercel فقط — لا في المستودع ولا في المتصفح؛ رفض: ‏401 مفتاح خاطئ · 422 سعر خارج [100..5,000,000] · 503 المفتاح غير مضبوط · 502 تعذّرت الكتابة |
| `DELETE /api/rate` | تصفير ذاكرة التطوير | ‏405 خارج التطوير (`RATE_DEV_MEMORY=1`) |

**دورة السعر في الواجهة:**
1. المسؤول يكتب السعر (أو يستخدم أزرار ±) ويضغط حفظ.
2. `SettingsPanel` يحفظ محلياً ثم `POST /api/rate` بالمفتاح المخزَّن في متصفحه
   (`badeel.rateWriteKey.v1`، يُكتب مرة واحدة في حقل «مفتاح النشر»).
3. نجاح ⇒ إشعار «تم الحفظ والنشر لكل الزوار» + يتحدّث صف «السعر العام النافذ لكل الزوار» وطابع «آخر نشر».
4. فشل ⇒ إشعار «حُفظ في هذا المتصفح فقط» مع السبب (مفتاح ناقص/خاطئ، انقطاع،…).
5. كل زائر: `lib/store.tsx` يجلب `GET /api/rate` مرة عند الفتح (`REMOTE_RATE`) فيطغى السعر
   الرسمي على أي سعر محلي قديم، وتُحسب به كل التحويلات والفلترة فوراً.

**متغيّرات البيئة المطلوبة في Vercel:**
- تُحقن آلياً من ربط Upstash: ‏`KV_REST_API_URL` · `KV_REST_API_TOKEN` · `KV_REST_API_READ_ONLY_TOKEN`.
- يُضاف يدوياً مرة واحدة: ‏`RATE_WRITE_KEY` (سرّ النشر؛ يُغيَّره المسؤول متى شاء لتدوير الحماية).
- ‏`RATE_DEV_MEMORY` **لا يُضاف في Vercel إطلاقاً** — يشغّل ذاكرة داخل العملية للاختبارات المحلية فقط.

**التحقق — `qa/rate-server-e2e.mjs` جديد (13/13) + تحديث `qa/rate-ownership-e2e.mjs` (21/21):**
- ‏GET قبل النشر = سعر الكود · مفتاح خاطئ/غائب = 401 · ‏50 و99 مليون = 422 · المحاولات المرفوضة لا تغيّر السعر.
- نشر صحيح ⇒ GET يعكسه فوراً، وزائر بسياق متصفح منفصل يرى التحويل به (‏100$ ≈ 1,450,000 ل.س).
- من اللوحة: كتابة المفتاح في حقله ⇒ حفظ 14,700 ⇒ إشعار النشر ⇒ GET = 14,700 ⇒ زائر جديد يرى 1,470,000 ل.س.

لقطات صاحب المنصة أظهرت نتيجة «سياسة الخصوصية» ونتيجة تصنيف الأثاث في صدارة
البحث عن اسم المنصة. السبب التقني: `alternates.canonical: "/"` كان في
`app/layout.tsx` فيُورَث لكل صفحة ⇒ دمج جوجل صفحات الخصوصية/التصنيفات في
فهرس الرئيسية (نتيجة بعنوان صفحة أخرى ومقتطف من أخرى).

- أُزيل canonical العام؛ كل صفحة تعلن رابطها: الرئيسية `/`، التصنيفات
  `/category/{slug}`، من نحن، كيف يعمل، أنواع السيارات… (فحص `qa/seo-canonicals.mjs`).
- عنوان الرئيسية ووصفها يبدآن بـ«عقارات وسيارات» كما طلب صاحب المنصة.
- استبعاد الصفائح الرقيقة من الفهرسة (`robots: noindex`): الصفحات القانونية
  الثلاث (خصوصية/شروط/كوكيز)، نشر إعلان، البحث الداخلي، تفاصيل الإعلان
  (تُبنى في المتصفح من ذاكرة الجهاز فلا محتوى لزاحف)، دون اتصال.
- الرئيسية/نشر/تفاصيل/كيف-يعمل كانت `"use client"` ولا يمكن تصدير metadata
  من مكوّن عميل — فصارت صفحة خادم رقيقة تُصدّر metadata وتركّب مكوّن العميل
  (`components/HomePageClient.tsx` وأخواتها).
- ملاحظة تشغيلية: تغيير العناوين يظهر في جوجل بعد إعادة الزحف؛ واختفاء
  النتائج القديمة يُسرَّع بطلب فهرسة الرئيسية من Search Console.

### 10.34 جسر الإعدادات العامة: الرقم والشعار والمدن لكل الزوار (موجة 24)

شكوى صاحب المنصة: «غيّرت رقم الهاتف من اللوحة فتغيّر عندي فقط». السبب: جسرا
السعر والحملات وحدهما كانا مرتبطين بـ KV، بينما الإعدادات تُحفظ في متصفح
المسؤول. الآن:

- `app/api/settings/route.ts`: GET حيّ (force-dynamic) يقرأ `site:settings`
  من KV؛ POST محمي بـ RATE_WRITE_KEY ينشر الحمولة؛ DELETE يلغي النشر.
- `lib/remote-settings.ts`: الشريحة العامة فقط (contactPhone/2، المصدر، مفتاح
  واتساب، الشعار، فيسبوك) + المدن — بلا سعر الصرف (جسر مستقل) وبلا حقول الأمان
  (تبقى محلية لكل جهاز بالتصميم).
- المتجر: `remoteSettings` يُجلب عند الإقلاع؛ الإعدادات/المدن الفعّالة = المنشور
  يطغى على المحلي، **إلا** في متصفح له تعديل محلي أحدث من آخر نشر (طابع زمني في
  `badeel.settings.localEditAt`) فيرى المسؤول تعديله فوراً حتى قبل النشر.
- الحفظ في «الإعدادات والأمان» ينشر السعر والإعدادات معاً (زر واحد)، وتبديل
  المدن في «المدن» ينشر فوراً؛ بلا مفتاح نشر ⇒ رسالة «حُفظ في هذا المتصفح فقط».
- فحص `qa/wave24-settings.mjs`: نشر رقم اختبار حيّ ⇒ متصفح معزول جديد يراه ⇒
  DELETE ⇒ يختفي. (المدن الفارغة في الحمولة تعني «أبقِ مدن الزائر» حمايةً.)
